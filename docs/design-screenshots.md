# Design-Screenshots (Smoke)

Hier können Mobile / Tablet / Desktop-Screenshots für die Abnahme **Design-Parität** abgelegt werden.

Vorgeschlagene Dateinamen (Beispiel):

- `docs/screenshots/mobile.png`
- `docs/screenshots/tablet.png`
- `docs/screenshots/desktop.png`

In `TASK.md` im Stand-Block darauf verweisen, sobald die Dateien existieren.
